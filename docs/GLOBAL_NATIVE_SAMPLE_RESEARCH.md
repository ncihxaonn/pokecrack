# Native sample units in global research

Research records may carry an optional `source_sample` containing a native count,
unit (`boxes`, `cartons`, `decks`) and precision (`exact_reported`,
`approximate_reported`, `lower_bound`). Such records keep `packs: null`, unknown
pack precision and no pack metrics. Product contents are never a conversion rule.
This field does not authorize a collector or admit production statistics.

Legacy records retain their original shape so existing bot-authored GitHub
batch fingerprints remain valid. Missing native evidence does not contradict a
known sample; conflicting native evidence quarantines all counts in the cohort.
