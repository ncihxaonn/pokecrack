# Future roadmap

Everything here is proposed, not implemented or promised. Preserve the free MVP boundaries until each phase has owner approval, tests, terms/privacy/security review and capacity evidence.

## Near term: prove the private demo

- Complete worker role CLI/job orchestration and public aggregate migration/tests.
- Expand synthetic fixtures and golden evaluation sets across languages/products/evidence tiers.
- Add reproducible aggregate versioning, correction ledger and admin health visibility.
- Validate Compose images/health on a Docker-capable host; run database reset/pgTAP and restore drill.

## Controlled live pilot

- Create account-bound Supabase/Vercel/VPS with least privilege and documented release evidence.
- Enable one official catalog API, then one metadata discovery adapter; measure quotas, drift and bias.
- Audit and pin a compatible OpenCLI CLI/Bridge before enabling one authorized read-only account adapter.
- Evaluate real AI models under hard budgets; keep fail-closed thresholds and fixture fallback for testing only.

## Quality and transparency

- Coverage/bias dashboard, provenance/source-diversity summaries and methodology changelog.
- Better dedupe/identity resolution with regression sets and false-merge monitoring.
- Scheduled source-policy/terms review and automated adapter fixture drift alerts.
- Independent statistical/security/accessibility review and public correction/takedown process.

## Capacity and resilience

- Metrics/alert backend, queue SLOs, off-site encrypted backups, repeated restore drills and documented RTO/RPO.
- Revisit Supabase/Vercel/VPS limits using measured usage; upgrade only with owner approval.
- Image digest/SBOM/signing and a controlled artifact promotion process.

Excluded unless separately reconsidered and approved: automatic purchasing, pack/store luck prediction, CAPTCHA bypass, proxy/stealth pools, public uploads/signup, full media retention, MiroFish/client extension, ads/affiliate/sponsorship/subscriptions/commercial or public paid API product. Commercial work starts only after `COMMERCIALISATION_CHECKLIST.md`; it is not part of this roadmap implementation.
